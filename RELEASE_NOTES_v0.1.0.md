# Release Notes — Cerne Code v0.1.0

---

## 🇧🇷 Português (Brasil)

**Cerne Code v0.1.0** — Primeiro lançamento oficial!

Agente de código local com interface gráfica nativa. Como o Claude Code CLI, mas em app desktop (Tauri + Vue).

### Funcionalidades
- Chat com IA local (Ollama, LM Studio, llama.cpp) ou cloud (OpenAI, OpenRouter, Anthropic)
- Execução de comandos PowerShell/CMD com detecção automática do shell
- Edição de arquivos com sandbox e aprovação manual (modo Manual)
- Skills: instruções reutilizáveis carregadas sob demanda pelo agente
- Servidores MCP: conecte ferramentas externas ao agente
- Sub-agentes e verificador automático de tarefas
- Pastas com controle de leitura vs leitura+escrita
- Interface multi-idioma (PT-BR, EN, ES, ZH)
- Instalador NSIS multilíngue
- Disclaimer de responsabilidade na primeira execução
- Auto-nomeação de sessões via IA
- Ícones Google Material Symbols

### Segurança
Modo Manual padrão, sandbox de edição, aprovação explícita por ação.

### 🔧 Como instalar
1. Baixe o arquivo `Cerne Code_0.1.0_x64-setup.exe`
2. Execute o instalador — ele detecta automaticamente o idioma do seu Windows
3. Se preferir outro idioma, use o seletor de idioma no início da instalação

## 🇺🇸 English

**Cerne Code v0.1.0** — First official release!

Local coding agent with native GUI. Like Claude Code CLI, but in a desktop app (Tauri + Vue).

### Features
- Chat with local AI (Ollama, LM Studio, llama.cpp) or cloud (OpenAI, OpenRouter, Anthropic)
- PowerShell/CMD command execution with automatic shell detection
- File editing with sandbox and manual approval (Manual mode)
- Skills: reusable instructions loaded on demand by the agent
- MCP Servers: connect external tools to the agent
- Sub-agents and automatic task verification
- Folders with read vs read+write control
- Multi-language interface (PT-BR, EN, ES, ZH)
- Multilingual NSIS installer
- Disclaimer on first run
- AI-powered session auto-naming
- Google Material Symbols icons

### Security
Manual mode by default, edit sandbox, explicit action approval.

### 🔧 How to install
1. Download `Cerne Code_0.1.0_x64-setup.exe`
2. Run the installer — it automatically detects your Windows language
3. If you prefer another language, use the language selector at the beginning of the installation

## 🇨🇳 中文

**Cerne Code v0.1.0** — 首个正式发布版本！

本地代码智能体，拥有原生图形界面。类似 Claude Code CLI，但采用桌面应用形式（Tauri + Vue）。

### 功能特性
- 与本地 AI（Ollama、LM Studio、llama.cpp）或云端 AI（OpenAI、OpenRouter、Anthropic）聊天
- 自动检测 Shell，执行 PowerShell/CMD 命令
- 沙盒编辑文件，需手动批准（手动模式）
- Skills：由智能体按需加载的可重用指令
- MCP 服务器：将外部工具连接到智能体
- 子智能体和自动任务验证
- 文件夹读写权限控制
- 多语言界面（PT-BR、EN、ES、ZH）
- 多语言 NSIS 安装程序
- 首次运行免责声明
- AI 自动命名会话
- Google Material Symbols 图标

### 安全
默认手动模式、编辑沙盒、每步操作需明确批准。

### 🔧 安装方法
1. 下载 `Cerne Code_0.1.0_x64-setup.exe` 文件
2. 运行安装程序 — 它会自动检测您的 Windows 语言
3. 如果您希望使用其他语言，请在安装开始时使用语言选择器
